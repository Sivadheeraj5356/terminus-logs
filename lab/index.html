Verifier

Integrity-first: oracle must pass, empty work must not, timeout is not a completed fail.

What every frozen package is checked against

  • Oracle harbor run -a oracle -k 1 reward 1.0 or the slug is dropped, not footnoted.
  • Agent reward 0.0 with no timeout/infra exception is valid fail.
  • Timeout, Docker, auth, credit-too-low, and 429 quota are infra.
  • Optional nop empty submission should score 0. A world that rewards empty work is a scaffold void.
  • Binary channel is Harbor rewards.reward. Rubric channel is off until we author one.
