Worlds

A world is a Harbor 0.22 package under tasks/latest/<slug>/: instruction.md, task.toml, environment/, solution/, tests/, and summary.md (UUID). These worlds are offline. Expert-time figures on catalog cards are author metadata, not measured wall clock.

This surface is the package contract. It is not a solve-rate introduction and it does not copy another lab’s chrome.

Verifier

  • Oracle must score 1.0 (harbor run -a oracle -k 1).
  • Empty submission (nop) must score 0, when that run exists.
  • Timeout is not a valid fail. Auth and Docker errors are infra, not stumps.
  • Binary channel = Harbor reward. Tests fraction only if the verifier exposes it. Rubric only if we author one.

Stump

stump_pct = valid_fail / completed_trials × 100. Completed trials are solved + valid fail. Timeouts and infra are excluded. Hidden until a denominator exists. No GRPO / σ until an 8-run group exists.
