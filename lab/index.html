Worlds Lab

Serious Terminal-Bench 2.1-style Harbor packages that data labs can license or outsource: unique hard worlds, oracle and tests, offline Docker environments, mixed languages and categories.

448 authored packages in private inventory. 100 in this public gallery — all author-labeled hard. Runtime is private Harbor 0.22 + terminus-2 / oracle. Model cells fill only from recorded Harbor jobs. Remaining analysis when API credits return.

    Public gallery of 100

    Unique slugs across TB categories and languages, selected from 448. The catalog lists every row. Batches 02–05 are frozen lists, not measured.

  3. 03

    Honest measurement

    Chips are solved / recorded trials, never padded to 5 or 8. Grok, GLM, and Kimi were not run. Empty cells stay — / not run.

Verifier

            
Integrity-first: oracle must pass, empty work must not, timeout is not a stump.

          

        

        

        

          
What every frozen package is checked against

          
    
            
  • Oracle harbor run -a oracle -k 1 reward 1.0 or the slug is dropped, not footnoted.
    • 
            
  • Agent reward 0.0 with no timeout/infra exception is valid fail.
    • 
            
  • Timeout, Docker, auth, credit-too-low, and 429 quota are infra.
    • 
            
  • Optional nop empty submission should score 0. A world that rewards empty work is a scaffold void.
    • 
            
  • Binary channel is Harbor rewards.reward. Rubric channel is off until we author one.
    •
