Applied Work

Worlds Lab

One hundred authored Harbor worlds. Fifty of them are the measured set, grown in tens. This is not another lab’s scores.

Runtime is private Harbor 0.22 + terminus-2. Going-forward trials are 5 per cheap arm. Chips light only after jobs exist, with the real denominator.

  1. 01

    Package contract

    instruction.md, Docker environment, oracle, and tests. Selected from 448; the gallery always lists all 100.

  2. 02

    Measure in tens to fifty

    Five frozen batches of 10. Cheap protocol: Haiku and a second arm, 5 independent trials each. Frontier 8-run history stays labeled as history.

  3. 03

    Valid-fail stump, not a variance poster

    Stump is valid fail over completed trials. Timeouts, Docker faults, credit-too-low, and 429 quota do not count.

Verifier

            
Integrity-first: oracle must pass, empty work must not, timeout is not a stump.

          

        

        

        

          
What every frozen package is checked against

          
    
            
  • Oracle harbor run -a oracle -k 1 reward 1.0 or the slug is dropped, not footnoted.
    • 
            
  • Agent reward 0.0 with no timeout/infra exception is valid fail.
    • 
            
  • Timeout, Docker, auth, credit-too-low, and 429 quota are infra.
    • 
            
  • Optional nop empty submission should score 0. A world that rewards empty work is a scaffold void.
    • 
            
  • Binary channel is Harbor rewards.reward. Rubric channel is off until we author one.
    •
