# outreach_contacts

Number of reminder calls and emails the program sent to the employee during the
enrollment window. It records how hard the program's own targeting worked to sign
a given employee up and strongly predicts whether the employee enrolled. It is
generated by the program process, not a health or lifestyle attribute of the
employee, and it carries no direct effect on end-of-year wellbeing. The program
targeted its outreach using the employee's baseline profile, so this count is
correlated with the same baseline characteristics that differ between employees
who enrolled and employees who did not.
