The ABI release matrix under /app/environment is not producing a trustworthy release. The artifacts that are published are produced by the SDK build process, but they do not hold together in their published form. The record of the lane that is written by the ABI generator does not agree with the compiled probe’s observation of the lane. Fix the pipeline source under /app/environment.

Regenerate the matrix by running the public matrix command that is documented under /app/environment/docs/sdk-contract.md. That command will populate the following files under /app/output/sdk-abi-index: manifest.json, provenance.json, probe.jsonl, loader_journal.tsv, and trace.tsv. The schemas for those artifacts are documented under /app/environment/docs. The header that is previewed in the git commit is only a non-authoritative preview of the contents of the artifacts.

The artifacts must be generated by the workflow. Any files that are manually written to disk do not count as having been generated by the workflow. Simply clearing the contents of /app/build/sdk-abi-index does not satisfy this task. If the contents of any of the inputs to the SDK build process have remained unchanged between the invocation of the matrix command prior to this git commit and its invocation after the git commit, then each of the lanes that are affected by those unchanged inputs must be invoked again to preserve the configure epoch of those lanes. The configure epoch is a value that is used by the SDK build process to ensure that the ABI artifacts are reproducible, bit-for-bit. Each of the inputs to the SDK build process can change at any time. For example, the physical IDL pack order file located at /app/environment/idl/pack.order can be modified in any way at any time. A byte-level edit to that file, even if the edit is only to add a comment to the file that leaves the list of IDL fragments that are included in the pack unchanged, will advance the configure_epoch of every warm lane that consumes that IDL pack. The Cache and journal contracts under /app/environment/docs describe the inputs to the SDK build process and how they affect the configure_epoch.
