Fit-row imputation and scaling are required. Numeric missing values are replaced with the fit-row mean, then sample standard deviation scaling is learned from those post-imputation fit values. Categorical missing forms are converted to the literal level missing; categorical imputation_value entries in missing_report.csv are the string missing, not the modal class. The design keeps every sorted fit-row categorical level as a one-hot indicator and does not drop a reference category.
