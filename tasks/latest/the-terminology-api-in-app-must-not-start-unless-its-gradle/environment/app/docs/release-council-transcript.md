for public synonym expansion.

## Meeting 18: checksum and lock schema
Asset locks must record repository, revision, per-file SHA-256 of local bytes, byte sizes,
source metadata digest, transcript digest, lock schema version `1.0.0`, route file map,
and Gradle dependency-lock digest. Lock JSON must be deterministic: sorted keys, no timestamps.

## Meeting 19: Gradle coupling
`./gradlew updateHfAssetLock` regenerates `/app/config/hf-assets.lock.json` from the local mirror,
transcript policy, and Gradle lockfiles. `./gradlew validateHfAssetLock` and `./gradlew check`
must fail when locks disagree. Spring Boot startup must enforce the same policy.
