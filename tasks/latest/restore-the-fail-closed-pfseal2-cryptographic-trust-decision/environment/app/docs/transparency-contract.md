# Cross-deployment transparency checkpoints

Every successful envelope finalization must append one row to `pfseal_transparency_checkpoints` in the same transaction as its replay state, rotation outbox, deployment audit link, audit head, and terminal job update. Failed envelopes append no checkpoint. If checkpoint construction or insertion fails, the whole successful finalization rolls back and the claimed job remains leased in `processing` state.

Construct the checkpoint from the prospective set of `pfseal_audit_heads` after applying the triggering audit link. Include every deployment head, not only the triggering deployment. Each deployment id must be a string whose UTF-8 encoding is 1 through 65535 bytes; sort heads by unsigned lexicographic comparison of those UTF-8 bytes. Every head sequence must be a JavaScript-safe positive integer and every head hash must be lowercase 64-character hexadecimal. Invalid head state is fatal.

The leaf for a head is SHA-256 of byte `0x00`, the deployment-id byte length as an unsigned 16-bit big-endian integer, the UTF-8 deployment-id bytes, the sequence as an unsigned 64-bit big-endian integer, and the 32 decoded audit-hash bytes. Build upper levels in order with SHA-256 of byte `0x01`, the 32-byte left hash, and the 32-byte right hash. When a level has an odd node count greater than one, duplicate its final node as the right child. A one-leaf tree uses that leaf directly as its root.

With no existing checkpoint, the next `checkpoint_sequence` is 1 and both `previous_checkpoint_hash` and `previous_event_mmr_root` are 64 zeroes. Otherwise select the numerically greatest sequence, require it to be JavaScript-safe, positive, and below `Number.MAX_SAFE_INTEGER`, require its checkpoint and event-root hashes to be lowercase 64-character hexadecimal, validate its event frontier as described below, then increment the sequence and chain from those hashes. Legacy audit heads without a checkpoint are allowed and enter the first root.

Checkpoints also form an append-only event Merkle Mountain Range. Its event leaf is SHA-256 of byte `0x02`, the new checkpoint sequence as unsigned 64-bit big-endian, the triggering job id as unsigned 64-bit big-endian, the 32 decoded snapshot `merkle_root` bytes, and the 32 decoded triggering audit-hash bytes. The frontier is a canonical JSON array indexed from height zero upward. Its length is the bit length of the checkpoint sequence, and element `h` is a lowercase 64-character hexadecimal peak exactly when bit `h` of that sequence is set; other elements are JSON `null`. No trailing null is possible. Whitespace, uppercase hex, missing slots, extra slots, and noncanonical JSON are fatal.

To append a leaf, carry it at height zero. While the existing peak at that height is non-null, replace the carry with SHA-256 of byte `0x03`, the 32 decoded existing peak as the left child, and the 32-byte carry as the right child; clear that peak and continue one height upward. Store the carry in the first empty slot. Compute `event_mmr_root` by visiting non-null peaks from highest height to lowest: the first peak is the initial root, then each later peak becomes SHA-256 of byte `0x04`, the current 32-byte root, and the 32 decoded later peak. A one-peak frontier uses that peak directly. Before appending, the worker must require the prior row's `frontier_json` to be canonical and shaped for its sequence, require `frontier_sha256` to equal lowercase SHA-256 hex of the UTF-8 frontier text, and independently bag its peaks to the stored `event_mmr_root`. Any mismatch is a fatal database error.

The new `checkpoint_hash` is lowercase SHA-256 hex of UTF-8 `PFSEAL-CHECKPOINT-V1\n` followed by canonical JSON containing exactly `checkpointSequence`, `eventMmrRoot`, `frontierSha256`, `headCount`, `jobId`, `merkleRoot`, `previousCheckpointHash`, `previousEventMmrRoot`, `processedAt`, and `triggeringAuditHash`. Store those values and the exact canonical frontier in the corresponding row; `created_at` is the effective worker time. Numeric ordering must never cast unsigned ids or sequences to text.
