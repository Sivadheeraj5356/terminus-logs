# Tapeout JSON schema

calibration_tapeout.json uses schema_version gaa-tapeout-v1. Fields include reference_temp_c, geometries array, iv_points, cv_points, contacts map from geometry_id to ohmic contact value, and measure_digest sha256 hex.

Each geometries row in the tapeout uses lowercase field names geometry_id, l_nm, w_nm, nfin, and split_group. The geometry manifest on disk may spell L_nm and W_nm with capital letters; characterize maps those lengths and widths into the lowercase tapeout keys.

Digest lines prefix iv rows with iv pipe geometry pipe vgs pipe vds pipe id_amps pipe temp_c using big-endian IEEE754 hex for each numeric field. CV rows prefix cv pipe geometry pipe vgs pipe cgg_f pipe temp_c with the same hex encoding. Points must be sorted before digest computation in ascending numeric order: IV rows by geometry_id, then vgs, then vds; CV rows by geometry_id, then vgs. Sorting compares the exact stored floating-point values as parsed from CSV, not rounded, truncated, or unit-rescaled sort keys, so two voltages that differ by less than a microvolt must still keep their true numeric order. Digest inputs are the stored gaa_tapeout floats as parsed from CSV without round12 or unit rescaling on characterization fields. characterize writes the gaa_tapeout file and its digest in one atomic write pass so the destination is only ever observed as the previous complete file or the new complete file, never a partially written one. The temp file is a dot-prefixed sibling in the destination directory named .{dest_basename}.tmp (for example .calibration_tapeout.json.tmp beside calibration_tapeout.json); characterize commits the sealed snapshot with rename from that sibling into the final tapeout path. Encoding helpers are defined in /app/scripts/digest_contract.py.
