Determine the common cubic crystal phase and calibration for the two diffraction scans in a study. The command is `/app/bin/cubic-index --study STUDY_PATH --output OUTPUT_PATH`. The study format, reflection rules, feasibility conditions, objective order, canonical tie-breaking, JSON certificate, diagnostics, limits, and publication behavior are defined in `/app/CUBIC_DIFFRACTION_PROTOCOL.md`.

Implement the scientific indexing calculation in `/app/src/indexer.rs`. The fixed parser and renderer will call `pub fn solve(study: &Study) -> Option<Plan>`. The JSON certificate includes the exact `optimal_count` and lowercase SHA-256 `digest` defined by the protocol. A valid result must be derived from the supplied study, handle the declared eight-peak-per-scan boundary within the time limit, and reproduce the same certificate on repeated runs. The bundled example writes `/app/result.json`; normal runs use the absolute path passed with `--output`.
