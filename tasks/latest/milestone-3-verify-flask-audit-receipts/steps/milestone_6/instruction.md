Recover the transparency log's entry leaf-canonicalization algorithm and implement it at /app/transparency/entrycanon.py (a flat module, no package, with /app/transparency on sys.path). The algorithm is not documented, so reverse-engineer it from the worked-example pairs under /app/transparency/entrylog/examples/. Each entry_NN.json and golden_NN.json pair records the submitted entry alongside its exact canonical_b64 (the canonical leaf bytes), canonical_sha256, payload_hash_input_b64, leaf_hash_hex, signed_input_b64, and a valid signature_b64. The log public key is in log_public_key.json. Diff entries against their canonical_b64 to recover which fields are in scope, their order, per-field value encodings, separators, framing, and how the leaf hash and signed input are derived; several of these behaviours interact, some depend on field values, and every plausible-but-wrong reading is contradicted by at least one example.

Expose four public functions. canonicalize_entry(entry: dict) -> bytes returns the byte-exact canonical leaf bytes matching canonical_b64. signed_input(entry: dict) -> bytes returns the byte-exact signed-input bytes matching signed_input_b64, verifiable under the log key. signed_scope(entry: dict) -> dict returns the normalized in-scope field projection with out-of-scope fields absent. Its values are NATIVE Python objects — the normalized value as it exists BEFORE its byte encoding, not the ASCII string embedded in canonical_b64. Each emitted field has exactly this Python type: log_id str, leaf_type str, index str (the 16-character zero-padded decimal), subject str (the comma-joined normalized names, "" when there are none), issued_at int (integer epoch MILLISECONDS), payload str (lowercase hex digest), issuer_id str (present only for a precert_entry), and origin str (present only when x_origin is present). In particular issued_at is an int and subject is a single joined str, even though both are rendered as strings inside the canonical bytes. leaf_hash(entry: dict) -> bytes returns the bytes matching leaf_hash_hex hex-decoded.

Also provide a CLI. The invocation python3 /app/transparency/entrycanon.py canonicalize --entry <path> --out <path> writes the raw canonical bytes, and python3 /app/transparency/entrycanon.py signed-input --entry <path> --out <path> writes the raw signed-input bytes.
