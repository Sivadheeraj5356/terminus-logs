Lab cooling spreadsheets disagree with thermal exports when normalization, masking, and curve-fitting steps from the operator runbook are skipped. Repair the Go project under `/app` so the CLI emits deterministic calibration artifacts that follow the documented scientific procedure.

Build with `go build -o /app/bin/thermalcal /app/cmd/thermalcal`. With no arguments, consume `/app/input_data` and write a top-level calibration report at `/app/output_data/calibration_report.json` plus `/app/output_data/intermediate/frame_summaries.jsonl` and `/app/output_data/intermediate/session_fits.jsonl`. With two arguments, treat them as input and output directories and create the full output tree, including nested intermediate folders such as `/app/output_data/nested/deep/out/intermediate`.

The active procedure is defined by `/app/docs/calibration_runbook.md` (see **Current Operating Profile**, **Mask and pixel inclusion semantics (ACTIVE)**, and **Cooling-curve fitting semantics (ACTIVE)**), `/app/input_data/manifest.json`, and the read-only Terraform constants module at `/usr/local/share/calibration_tf`. Runtime must not download tools from the network.

`/app/output_data/calibration_report.json` must include `schema_version`, `terraform_version`, `input_digest`, `sessions`, and `global_summary`. Each `/app/output_data/intermediate/frame_summaries.jsonl` row must include `session_id`, `frame_id`, `timestamp_s`, and `trimmed_mean_c`. Each `/app/output_data/intermediate/session_fits.jsonl` row must include `session_id`, `ambient_temperature_c`, `cooling_rate_k`, and `half_life_s`. Sessions sort by `session_id`; frames sort by manifest timestamp then `frame_id`. Outputs must be byte-stable across repeated runs on identical inputs.

The verifier rebuilds the CLI from current sources and may reorder manifest rows, rewrite manifests with CRLF endings, rename session identifiers, perturb Terraform constants, and synthesize new 16-bit PNG sessions under workspace paths such as `/tmp/trc_reorder_in`, `/tmp/trc_rename_in`, `/tmp/trc_synth_in`, and `/tmp/trc_tf_out`. Hand-written static outputs are insufficient when the verifier regenerates inputs. The implementation must handle at least four sessions, eighty frames, and 512×384 16-bit PNG frames within the verifier timeout.
