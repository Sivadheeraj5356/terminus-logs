The lab inputs are `/app/task_file/input_data/samples.tsv`, `/app/task_file/input_data/panels.tsv`, and `/app/task_file/input_data/config.txt`. Build a native C optimizer at `/app/task_file/opt` from `/app/task_file/src/main.c`. Running it from `/app/task_file` must write `/app/task_file/output_data/batches.json`; it must also accept `/app/task_file/opt <input_dir> <output_dir>` and use those directories instead. The JSON shape is `{"panels":[{"panel_id":"A","sample_ids":["P01"]}],"runs":[{"lane":"L1","panel_ids":["A"]}]}`.

Every mandatory sample is assigned exactly once, optional samples at most once, and a sample may only use a panel listing its family. Per-panel `reagent_a_cap`, `reagent_b_cap`, and `slot_cap` are hard limits. The plan must cover every `families=` value, meet `risk_floor=`, avoid `forbidden_pairs=`, separate cohorts when `cohort_separation=1`, spread `sentinel_families=` across at least `min_sentinel_panels=`, and complete at least `linked_pair_floor=` same-panel linked pairs. If either member of a linked pair is selected, both must be selected on the same panel.

The `runs` list must schedule every nonempty panel exactly once across `lane_count=` lanes named `L1`, `L2`, and so on. Each used lane needs between `min_lane_panels=` and `max_lane_panels=` panels, adjacent class transitions from `setup_costs=` must respect `lane_setup_cap=`, and total setup must respect `total_setup_cap=`; in the shipped config this is `total_setup_cap=14` with `setup_target=14`. Each `lane_targets=` entry is also hard: that lane's scheduled panels must collectively contain an assigned sample from the named family. Any violation scores zero.

For valid plans, `total_score` combines captured risk, required-family coverage, reagent efficiency, optional coverage, panel stewardship, sentinel spread, and setup efficiency; it must be at least `0.91`. Strict scoring must be at least `0.92` and penalizes these triggers: `reagent_score < 0.80`, `coverage_score < 0.72`, `stewardship_score < 0.70`, `sentinel_score < 1.0`, `setup_score < 1.0`, or `linked_pair_count < linked_pair_floor`. Verifier copies can tighten capacities, add required families/samples/panels, change setup budgets, append forbidden pairs, and add mandatory-linked optional partners in the same run, so parse the live TSV/config files and recompute a fresh assignment and lane order. Use `cd /app/task_file && gcc -O2 -std=c11 src/main.c -o opt && ./opt`.
