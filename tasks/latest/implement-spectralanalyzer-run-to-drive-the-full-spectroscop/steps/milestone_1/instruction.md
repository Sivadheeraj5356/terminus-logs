The `parse_containerfile` method in `/app/lib/spectral_analyzer.rb` currently returns an empty hash — implement it to extract the key-value parameters from `/app/Containerfile`. Lines starting with `#` at the beginning of a line are comments. Keys and values may have surrounding whitespace. A `#` character mid-line is part of the value — do not treat inline hashes as comments. Parameters may have empty values. Numeric values should be coerced to Float, everything else stays as a string. Return the result as a hash with lowercase symbol keys.

Once the parser works, create an executable script at `/app/bin/parse_spec.rb`. It should accept an optional file path argument (defaulting to `/app/Containerfile`), print each parameter as `key: value` on its own line to stdout, and exit with 0 on success or 1 on failure.
