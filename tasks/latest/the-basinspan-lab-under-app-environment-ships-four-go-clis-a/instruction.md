The BasinSpan lab under /app/environment ships four Go CLIs and a Rust merge kernel for neuron-aligned feedforward weight merging. The tree builds and runs, but campaign output still disagrees with /app/environment/docs/basinspan_contract.txt. Fix the Go and Rust sources under /app/environment to match that contract, then rebuild with /app/environment/scripts/rebuild.sh (see /app/environment/docs/toolchain.md). Hand-written or static output under /app/output is insufficient; the normal pipeline must regenerate every artifact.

After rebuild you should have basinspan-run, basinspan-probe, basinspan-audit, and basinspan-inspect in /app/environment/build/. basinspan-run reads the manifest and policy, evaluates each pair profile, and writes merge_report.json, alignment_trace.csv, merge_journal.jsonl, and barrier_certificate.json under /app/output, plus align_cache.json and merge_ledger.json under /app/var/basinspan. Use --reset to clear persisted state before a campaign; without --reset each run increments generation and ledger counters as the contract describes. BASINSPAN_MANIFEST, BASINSPAN_PAIR_DIR, and BASINSPAN_POLICY_EPOCH override the manifest path, pair directory, and policy epoch.

The contract defines 4→6→6→2 ReLU pairs, activation Pearson correlation, Hungarian assignment with column permutation propagation, aligned merging, eval and naive MSE, barrier_value, digests, cache keys, stable_runs, and probe/audit/inspect formats. align_model_b must permute output-layer columns by the last hidden permutation both inside the hidden-layer loop (when L+1 is the output layer) and again in the explicit post-loop step described in the contract. align_cache.json must include a top-level policy_epoch field, and cache hits are valid only when that epoch matches the active policy epoch. Rejected profiles leave merge_digest_hex empty. Accepted profiles must agree across report, CSV, journal, certificate, persisted state, and the auxiliary CLIs. Kernel and library behavior must be correct, not only CLI formatting. Grading rebuilds from source, runs basinspan-run with and without --reset, restores pair JSON from /var/lib/verifier/pairs-vault, may mutate fixtures or policy epoch, and compares results to an independent reference within the tolerances stated in the contract.
