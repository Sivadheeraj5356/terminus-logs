# Contain the INC-8821 certificate-trust compromise

Security engineering needs a defensible containment decision for four incident cases. The evidence under `/app/environment/evidence`, case overlays under `/app/environment/cases`, and authority documents under `/app/environment/authorities` are the complete record. Reconcile them using the public rules in those documents; filenames and record order carry no authority.

Output-only work is allowed; no supplied application is broken. Source code under `/app/environment` must be fixed by implementing the interface in `/app/environment/adjudicator.py`. The verifier removes `/app/out` and runs `/app/environment/run.sh`; that command must regenerate, for every profile, `/app/out/<profile>/trust_assessment.json`, `/app/out/<profile>/containment_plan.json`, and `/app/out/<profile>/decision_commitment.bin`. Hand-written outputs that cannot be regenerated are insufficient. Execution is offline and must use only the Python standard library.

The JSON schemas, enum domains, sorting, citation form, temporal rules, conflict handling, counterfactual requirement, canonical encoding, and commitment format are specified in `/app/environment/contracts`. Assess every subject, derive valid and rejected trust paths, validate independent witness quorum, apply scoped emergency exceptions, propagate compromise, choose the deterministic minimum safe containment set, and preserve critical service availability where possible. Treat unresolved governing conflicts conservatively. The same implementation must handle all cases without case-specific answer tables.
