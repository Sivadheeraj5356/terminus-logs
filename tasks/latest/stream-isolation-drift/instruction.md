# Stream Isolation Drift

The derivative runtime under /app/environment emits JSONL run records and per-pass JSON summaries under /app/output. Serial runs look consistent. Under concurrent admission with checkpoint continue, norm summaries often stay within plan tolerance while pass files disagree with a serial baseline for the same plan, seed, and mode. Fix the source under /app/environment so the pipeline regenerates correct evidence. Output-only work is not allowed. Do not edit /tests/ or fabricate output files. Static or manual output creation is insufficient; the verifier deletes /app/output before each scenario and the normal run/continue pipeline must regenerate artifacts. Build, CLI flags, plan choices, and artifact schemas are in /app/environment/docs/contract.md; invoke the release binary through the run/continue pipeline described there.

For a fixed plan, seed, and mode, sorted pass-record digest chains must agree between a serial uninterrupted run and a concurrent run that checkpoints mid-training and continues. Pass-record `mode` is stored for each pass but is not part of the digest formula. Successful runs emit `/app/output/run_transcript.jsonl` (seq, job, phase, slot, payload_digest, pass_index), per-pass JSON under `/app/output/pass_records/` (stream_fingerprint, open_slots, mode), and `/app/output/vault/manifest.json` (last_generation, last_pass, open_count). Digest formulas and CLI details are in the contract.
