The workbook engine under /app should be implemented in Dart only. Put the source under /app/src and make /app/src/main.dart the runnable entrypoint. The verifier runs it directly as `dart /app/src/main.dart <input-json> <output-dir>`, not through `dart run`. It must work with arbitrary input and output paths, fail nonzero for a missing input file, overwrite stale output files, and write deterministic JSON stage files into the requested output directory.

The full spreadsheet contract is in /app/docs/SPEC.md. Follow that document for formula discovery, dependency extraction, edit timing, recalculation, cycle/error handling, named ranges, output schemas, sorting, and checksums. In particular, the audit stages use the final post-edit formula registry, while the dependency graph is the graph discovered before edits are applied; formulas introduced by edits still appear in final formula/audit/metric counts, but have no pre-edit dependency row expansion beyond the empty default described in the spec. Do not use Python or another helper interpreter from the Dart solution.
