Difficulty Explanation
Hard fits how this plays out: `arctl` readiness can look green while `/app/output/rule_lineage.json` still drifts. The broken pieces are spread across driver (LocalReady short-circuit), compile merge (tier order, +=/-= /!, first-encounter append opener split, last-touch authority), load selection, enforce folding (revoked / seeded yard ledger), and inspect note emission (`input_tree` / `durable_state` / `emission`). Patch readiness alone and relay still mis-folds classlist; patch merge alone and yard still resurrects `drain` from seeded state; skip note surfaces and inspect stays incomplete. People also tend to hand-write the lineage JSON instead of repairing the Go reload path.

Solution Explanation
I chased the full reload pipeline rather than a one-line readiness tweak. First I stopped LocalReady from skipping apply when the tree digest matched. Then compile merge: weaker-to-stronger overlay, delete/append/remove/set, first `+=` initializes action/field via `:` split, later `+=`/`-=` mutate the comma-list field only, and observed_authority follows the last touching tier. Load picks the active bundle; enforce fold keeps revoked classes out and lets live fixtures replace seeded stale rows. Inspect emits notes naming `input_tree`, `durable_state`, and `emission`. Once those lined up, relay/depot/yard surviving rows and digests matched across repeated reloads, and a second yard cycle kept `drain` gone with generation advancing per reload.

Verification Explanation
Pytest rebuilds `/app/bin/arctl` from `/app/environment`, runs reload/inspect on relay, depot, and yard, derives expected winners from the fixtures (last-touch authority, append opener split, generation per reload), and compares that to the regenerated lineage after deleting or poisoning `/app/state` and `/app/output`. It asserts readiness cannot hide stale rows, seed tombstones stay absent, inspect is read-only with stable commit digests, provenance notes name `input_tree`/`durable_state`/`emission`, and partial fixes on one profile cannot satisfy the full matrix. Editing the JSON by hand or patching tests does not help — the suite regenerates through the normal arctl path every time.
