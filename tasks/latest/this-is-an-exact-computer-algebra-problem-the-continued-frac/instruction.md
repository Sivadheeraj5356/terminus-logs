This is an exact computer-algebra problem: the continued-fraction expansion, convergents, and periodicity of a real algebraic number selected by root index. Every reported quantity is computed in exact arithmetic with no floating point.

You are given an integer polynomial and must report the continued fraction of one of its real roots, exactly. The work is done in Julia: the file /app/src/solver.jl already contains the standard-input to standard-output harness, and you complete the compute function it calls. Run it with `julia /app/src/solver.jl`, reading the problem from standard input and printing the answer. Use only the provided files and Julia's standard library, and compute everything with exact arithmetic, Julia's Rational{BigInt} and BigInt, never floating point.

The input is four lines. The first line is the degree d of the polynomial, with 1 <= d <= 6. The second line is d+1 space-separated integers c_0 c_1 ... c_d, the coefficients of P(x) = c_0 + c_1 x + c_2 x^2 + ... + c_d x^d; the leading coefficient c_d is nonzero and every coefficient is at most one million in absolute value. The third line is a positive integer r, a one-based index into the real roots of P. The fourth line is a positive integer k, with 1 <= k <= 30, the number of partial quotients requested.

List the distinct real roots of P in increasing order, counting a repeated root only once. It is guaranteed that P has at least r of them; let alpha be the r-th one in that order. No isolating interval is given.

The continued fraction of alpha is the sequence a_0, a_1, a_2, ... defined by starting with x_0 = alpha and repeating a_i = floor(x_i) and x_{i+1} = 1 / (x_i - a_i). Here floor is the greatest integer not exceeding the value, so a_0 may be zero or negative while every later a_i is a positive integer, and each fractional part x_i - a_i lies in the half-open interval from 0 to 1. If some fractional part x_i - a_i is exactly zero the sequence stops and a_i is its final term; this happens exactly when alpha is rational. The value x_i is called the i-th complete quotient.

The convergents are the rationals h_i / k_i built from the partial quotients by the standard recurrence with h_{-1} = 1, h_{-2} = 0, k_{-1} = 0, k_{-2} = 1, and then h_i = a_i * h_{i-1} + h_{i-2} and k_i = a_i * k_{i-1} + k_{i-2} for i >= 0. The h_i and k_i can grow far beyond 64-bit range, so treat them as arbitrary-size integers.

Report exactly six lines. Each line is a label, then a space, an equals sign, a space, and the values separated by single spaces. The first line is labelled count and gives a single number m, the number of partial quotients you report; this is the smaller of k and the total length of the continued fraction, so m equals k unless the expansion terminates first. The second line is labelled quotients and gives a_0 a_1 ... a_{m-1}. The third line is labelled numerators and gives the convergent numerators h_0 h_1 ... h_{m-1}. The fourth line is labelled denominators and gives the convergent denominators k_0 k_1 ... k_{m-1}. The fifth line is labelled terminated and gives 1 if the continued fraction is finite and you printed all of it, its length being at most k, and 0 otherwise. The sixth line is labelled period and gives a single number: a continued fraction is eventually periodic exactly when alpha is a quadratic irrational, meaning its minimal polynomial has degree two, and in that case you report the length of the repeating block, defined as i minus j for the first pair of indices 0 <= j < i < m whose complete quotients coincide, x_i = x_j, scanning i upward; if no such repetition occurs among the m complete quotients you computed, including the always-applicable case of a rational or higher-degree alpha, report 0.

Two complete quotients are equal only when they are equal as exact real numbers, so this must be decided exactly and never by a floating-point comparison.
