This is a numerical computation in exact linear algebra, the reconstruction of a univariate polynomial from a scheme of derivative conditions. Each problem fixes a degree bound N, so the unknown polynomial has N coefficients and degree below N, together with a list of conditions. Every condition is three integers, a point x, a derivative order j, and a value v, and it asks that the j-th derivative of the polynomial at x equal v, with the zeroth derivative being the value itself.

The conditions are not required to be nicely shaped. The derivative orders at a point need not be contiguous, so a point may fix its value and its second derivative while saying nothing about its first; a point may fix only a derivative and never its value; the same point and order may appear more than once; and the number of conditions may fall short of N, equal it, or exceed it. A problem may therefore have exactly one polynomial of degree below N that meets every condition, or none at all, or more than one.

For each problem the computation decides which of the three cases holds and backs its verdict with evidence. When exactly one polynomial fits, it reports the coefficients. When none fits, it reports that none does and gives one multiplier per condition, chosen so that weighting the conditions by those multipliers cancels completely on the polynomial side yet leaves a nonzero total on the value side, which no polynomial could meet. When more than one fits, it reports that many do and gives two different polynomials that each meet every condition. Every reported value is an exact rational in lowest terms; the arithmetic is carried out exactly, from first principles, and never uses floating point.

Only the standard library is available, there is no network, and no separate program may carry out the arithmetic. The program is written from scratch as solver.rs in /app and built there by running make; each problem file is named by the sole argument, and the exact layout of a problem and of an answer follows the notes under /app/docs.
