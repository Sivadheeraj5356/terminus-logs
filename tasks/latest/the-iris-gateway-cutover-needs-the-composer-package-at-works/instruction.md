The package already contains a draft walker and digest exporter — repair them so Composer/Phinx can publish a build-ready module graph, land it into the dependency database named by the active paths file, and pin a checksummed lock digest the release gate can verify.

Path bindings live in /workspace/config/paths.json. Use proxy_export and cutover_register from that file (other path keys are historical or smoke mirrors). Start from /workspace/docs/handover-index.md for the cutover memo and register legend.

Success looks like this. iris-prov normalize (--export, --paths, --out) writes /workspace/output/normalized-graph.json as two-space JSON with a trailing newline that validates against /workspace/schemas/normalized-graph.schema.json; matched replace directives use edge_kind replace. Missing export → stderr export not found, non-zero exit, no --out write. Incomplete export_meta roots → stderr export_meta incomplete, non-zero exit, no --out write.

iris-prov migrate (--graph, --paths) creates and populates the SQLite file at that paths file's sqlite_path (tables module_units, module_edges, replace_rules), leaves the graph bytes unchanged, and must honor that sqlite_path even when it differs from the smoke database named in /workspace/iris-provenance/phinx.php. Missing graph → stderr graph not found, non-zero exit.

iris-prov export-digest (--paths) reads that paths file's sqlite_path and writes its digest_path and checksum_path. Each digest line is compact JSON with a kind discriminator whose only allowed values are module, edge, and replace (not replace_rule). The checksum file must be exactly one lowercase 64-character hex digest plus a trailing newline (bare hash only — not a GNU sha256sum two-field line with a path). Missing sqlite → stderr sqlite database missing, non-zero exit, no digest/checksum writes. /workspace/iris-provenance/scripts/verify-provenance.sh rejects IRIS_PROV_SKIP_INTERNAL_PHPUNIT on stderr with a non-zero exit before any digest work; otherwise it confirms digest-checksum.sha256 matches a fresh hash of dependency-digest.txt (digest checksum mismatch on stderr on failure; provenance verify ok on success).
