# Glossary

- **Canonical panel id**: resolved catalog key after following `alias_of`, used to join dye reformulations, export routes, loom letters, merchant transfers, school recitals, and pattern anchors.
- **Recital gate**: dye-recipe eligibility requires a documented school recital on or before the reformulation year.
- **Genealogy journal**: halt/resume scratch register at `/app/output/.genealogy_journal.json` for interrupted bundle runs.
- **Clipped export-route span**: export-route epochs bounded by a bundle genealogy snapshot before dye or school-continuity math.
- **School continuity**: percentage of covered years on that span, published to four decimal places.
- **arms_length sale**: merchant-transfer row whose `kind` string equals `"arms_length"`, required for transfer-year relay coverage.
- **reset_drift**: dye-reformulation flag that sets the running dye factor to `1.0` at that year.
