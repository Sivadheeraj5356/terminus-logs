# Glossary

- **Commitment**: published `server_seed_hash` before pulls execute
- **Pity floor**: forced rare-or-better tier after consecutive sub-rare pulls
- **Receipt**: per-pull HMAC proving server knowledge of outcome
- **Session**: one banner opening sequence for a player
- **Ledger**: persisted pity counters keyed by player and banner
- **Session digest**: HMAC over session id and kept receipts
