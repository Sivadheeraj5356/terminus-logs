Rift Conclave is a deterministic two-player abstract strategy game. For each tournament position, the league needs the exact guaranteed score and principal variation under perfect player and rival play. Use the official game rules in `/app/task_file/arena_rules.md`; positions vary in their boards, hands, omen sets, round horizons, and resources.

Complete the Go match analyst beginning at `/app/task_file/main.go` and build `/app/task_file/conclave` from the Go package in `/app/task_file`. The league runner compiles that package with `go build` before scoring, so the position analysis must remain in `main.go` or additional `.go` files there; a script or prebuilt executable is not a substitute. Go and `gofmt` are available on `PATH`.

The match analyst must solve the position itself without launching helper processes or using network access. It accepts exactly two positional arguments—an input JSON path and an output JSON path—writes the exact result schema from the rules, prints nothing on success, and returns nonzero without creating the output when the arguments or position are invalid. Analyze `/app/task_file/input/public_match.json` and leave `/app/task_file/output/adjudication.json` for review.

Grading compares parsed JSON exactly, including the guaranteed score, the complete canonical principal line, every final site field, local action tie-breaks, null fields, and ordering. Compatible positions use rules version 1, 2–4 sites, 1–6 cards, 0–5 omens, 1–5 rounds, and integer values within the bounds stated in the rules. Do not modify the public input or rules file.
