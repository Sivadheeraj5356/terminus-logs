# Advisory MRA-2024-019 — Temurin JIT miscompilation report

Issued: 2024-11-05
Status: withdrawn (2024-12-02)

## Summary

A field report from the Fenn Hollow archive station suggested that the
Temurin 21 runtime miscompiled a tight loop in their resampling tool,
corrupting output silently. Given the spectral service runs on the same
runtime family, this advisory was issued as a precaution pending
reproduction.

## Disposition

The Fenn Hollow team traced the corruption to a failing memory module on
the host in question. No miscompilation could be reproduced on validated
hardware. This advisory was withdrawn on 2024-12-02. Withdrawn advisories
are retained in the register for the permanent record and are not in force;
withdrawal, unlike closure, records that the underlying finding was
determined to be unfounded.
