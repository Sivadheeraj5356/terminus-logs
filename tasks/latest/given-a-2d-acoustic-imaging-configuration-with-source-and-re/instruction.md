Given a 2D acoustic imaging configuration with source and receiver positions around a circular aperture and observed waveform data from multiple source-receiver pairs, implement a ray-based acoustic tomography system that computes straight-ray travel times, models frequency-dependent attenuation, performs iterative velocity reconstruction using travel-time gradient descent, and quantifies reconstruction uncertainty from the diagonal Hessian approximation. The program must read configuration from `/app/config/settings.json`, data from `/app/data/fwi/` (containing `sources.json`, `receivers.json`, and `observed_data.json`), and write the inversion report to `/app/output/fwi_report.json`.

The travel-time for each source-receiver pair is computed as: `travel_time_us = euclidean_distance_in_grid_cells × dx_mm ÷ avg_velocity_mps × 1000` where `avg_velocity_mps` is the arithmetic mean of all cells in the current velocity grid and `euclidean_distance_in_grid_cells = sqrt((sx-rx)² + (sz-rz)²)` using integer grid indices. The initial velocity grid is uniform at `initial_velocity_mps` from settings. All reconstructed velocity values must lie in the range [1000, 2000] m/s. The `frequencies_used` array in the output must be sorted in ascending order.

The output JSON must contain a top-level object with: `"forward_modeling"` (array sorted by source_id, each with `"source_id"`, `"ricker_wavelet"` array of floats for the source time function rounded to 6 decimal places, `"max_amplitude"` rounded to 6 decimal places, `"travel_times_us"` array of estimated first-arrival times to each receiver rounded to 6 decimal places), `"attenuation_model"` (array sorted by frequency ascending, each with `"frequency_mhz"`, `"attenuation_coefficient"` rounded to 6 decimal places computed from power-law α₀·f^n, `"phase_velocity_correction"` = (α₀/π) × f^(n−1) × log(f/f_ref + 1e-10) rounded to 6 decimal places where f_ref = minimum frequency in the source frequency list), `"gradient_computation"` (array per iteration sorted by 0-based iteration index, each with `"iteration"` starting at 0, `"misfit_value"` rounded to 6 decimal places as sum of squared travel-time residuals, `"gradient_norm"` rounded to 6 decimal places, `"max_gradient"` rounded to 6 decimal places, `"step_length"` = step_length_initial × step_length_reduction^iteration rounded to 6 decimal places), `"velocity_reconstruction"` (object with `"reconstructed_velocity"` as 2D array [nz][nx] rounded to 6 decimal places, `"mean_velocity_mps"` rounded to 6 decimal places, `"velocity_range"` two-element [min, max] array), `"uncertainty_map"` (object with `"diagonal_hessian"` as 2D array rounded to 6 decimal places, `"mean_uncertainty"` = mean of all diagonal_hessian values rounded to 6 decimal places, `"max_uncertainty"` = max of all diagonal_hessian values rounded to 6 decimal places, `"confidence_map"` as 2D array of 1/(1+H_ii) rounded to 6 decimal places), and `"inversion_summary"` (object with `"total_forward_solves"` = num_sources × num_inversion_iterations, `"total_adjoint_solves"` = num_sources × num_inversion_iterations, `"final_misfit"` rounded to 6 decimal places, `"misfit_reduction_percent"` rounded to 6 decimal places, `"converged"` boolean true if misfit decreased, `"frequencies_used"` array sorted ascending). All floating-point values rounded to exactly 6 decimal places, output must be deterministic.

Build command: `g++ -O2 -std=c++17 -o fwi_ultrasound fwi_ultrasound.cpp`. The binary accepts: `--config <path> --data-dir <path> --output <path>`. If invoked with no arguments, the program must exit with a non-zero status code.
