The distributed columnar compaction optimizer at /app ships columnarctl, a C++ CLI that ingests CLFC binary fragment catalogs through a staging snapshot, exports merge plans across row-range overlaps, validates plans, and repairs broken orderings. The implementation does not match the published contracts.

Behavioral rules, catalog layout, merge plan JSON, scan cost accounting, replica policy, and the ingest snapshot contract live under /app/docs/COMPACTION_CONTRACT.md and the other documents it references. Rebuild with make -C /app before testing. Invoking columnarctl with no arguments or with an unknown subcommand prints the single token USAGE on stderr and exits with status 2. All other failed subcommands print exactly one error token on stderr and a non-zero exit status as defined in /app/docs/COMPACTION_CONTRACT.md. Successful validate and repair emit one JSON object on stdout. Sample catalogs under /app/data/catalogs/ are for local experimentation; grading may use additional CLFC catalogs that are not shipped in the image but follow the same format.
