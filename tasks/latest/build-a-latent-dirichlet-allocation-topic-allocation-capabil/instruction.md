Build a Latent Dirichlet Allocation topic-allocation capability under /app on the supplied working Rust workspace. Implement patent document ingest, corpus staging, a deterministic collapsed-Gibbs sampler, a posterior count ledger, and a sealed topic rollup export according to /app/docs/cli.md, /app/docs/document-format.md, /app/docs/vocabulary.md, /app/docs/initialization.md, /app/docs/conditional.md, /app/docs/count-ledger.md, /app/docs/burn-in.md, /app/docs/topic-ranking.md, /app/docs/rollup-export.md, /app/docs/decoy-tfidf.md, and /app/docs/crate-modules.md.

ldactl ingest reads JSON patent documents from the configured inbox and writes /app/state/lda-corpus-staging.json. ldactl sample reads only that corpus snapshot, runs the collapsed-Gibbs sampler, and writes /app/state/lda-count-staging.json. ldactl export reads only the two state snapshots and writes /app/output/lda-topic-rollup.json. ldactl status reports from state and never reads the output. Preserve deterministic ordering and byte identity on unchanged reruns.

Service defaults, including the topic count, Dirichlet hyperparameters, sweep count, burn-in, seed, and top-term count, live in /app/config/ldactl.toml. An absolute TB3_LDA_ROOT overrides the configured inbox for ingest; relative values are ignored. Missing prerequisite state must fail without creating a downstream artifact.
