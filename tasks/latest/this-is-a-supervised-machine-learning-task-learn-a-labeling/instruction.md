This is a supervised machine-learning task: learn a labeling rule from labeled examples and predict labels for new examples. Each instance is a directory with two files. train.csv holds labeled training examples, one row each of four small integer features f0, f1, f2, f3 with a 0 or 1 label. test.csv holds unlabeled examples with the same four features. A single hidden rule, fixed within the instance, generated every training label, and the same rule labels the test examples. The task is to learn that rule from the training examples and predict the label of each test example.

The examples form an ordered sequence, and the rule the model must learn depends on the current example's features together with a bounded amount of information carried from earlier examples, so a model that treats the examples as independent will not fit the labels; not every feature necessarily matters. The carried information is small and integer-valued — think of a single running counter that accumulates along the sequence and resets to zero at a hidden bound — and the parameters that govern the rule lie in a modest range. Each instance has its own hidden parameters, so the rule is learned from each instance's own training examples rather than memorized once. The training labels let a learned model check itself on the training examples, while the graded instances are held out with new examples and new parameters; scoring is by prediction accuracy on the hidden labels, so a model that fits the training examples without recovering the underlying rule generalizes poorly and scores poorly.

You deliver your learned model as a Rust program in the crate at /app/environment, which builds offline. It is run once per instance as /app/environment/target/release/solver on the instance directory, and it outputs its predicted labels as one JSON document. A worked public instance is provided under /app/environment/data. The data and output formats, what is guaranteed about the rule, and the scoring rule are in /app/environment/docs/contract.md.
