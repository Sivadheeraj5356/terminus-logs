Build an underwater habitat supply chain planner under /app that compiles mission cargo into a reproducible resupply build pipeline. The pipeline ingests mission workload under /app/data/mission, materializes dependency-ordered staging artifacts under /app/state through tide timing, berth assignment, cargo priority, cold-storage limits, lane window rules, and transfer certification, then exports deterministic resupply-plan.json and utilization-report.json under /app/output. Implement the habitat-resupply-ingest and habitat-resupply-export command-line tools: habitat-resupply-ingest reads the mission directory and writes validated staging artifacts; habitat-resupply-export compiles only certified staging into final build outputs without reopening raw mission inputs.

Ingest must write seven staging files under /app/state: tide-snapshot.json, rov-index.json, berth-staging.json, transfer-cert.json, export-bind.json, o2-priority-freeze.json, and ingest-manifest.json. Each successful export must write /app/output/resupply-plan.json and /app/output/utilization-report.json and must persist /app/state/export-seal.json recording the frozen bind and plan fingerprint for the run. Each state and output artifact must include only the hash fields required by that artifact schema under /app/docs, and those values must match the digest definitions in the contract documents. Keep re-ingest stable on unchanged mission input and keep repeat exports byte-identical.

The /app/lib scripts are scaffolds that you implement per the contract documents. Start from /app/docs/cli.md and follow /app/docs/tide-offset-windows.md, /app/docs/berth-clock-band.md, /app/docs/lane-window-offset.md, /app/docs/wave-buffer.md, /app/docs/wave-scaling.md, /app/docs/psi-gap-buffer.md, /app/docs/transfer-cert.md, /app/docs/export-plan.md, /app/docs/berth-staging.md, /app/docs/o2-priority-freeze.md, /app/docs/export-bind.md, /app/docs/ingest-manifest.md, and /app/docs/export-seal.md plus the schema documents they reference. Determine which modules belong on the ingest and export paths from the contract documents.
