Bring streaming CTC caption inference back into agreement with the speech recognition model used for acoustic-frame decoding. Softmax-normalized logits must become a deterministic n-best transcript set—collapsed tokens, acoustic and phrase-bias log scores, token-frame alignments, and calibrated confidence—matching batch and streamed evidence alike. The accepted inference behavior is defined in `/app/decoder-notes/` (`ctc-prefix-probability-note.md`, `streaming-state-note.md`, `phrase-bias-note.md`, `alignment-and-confidence-note.md`).

Utterance packages reach `/app/build/caption-beam` with per-frame class logits, a token vocabulary and blank index (blank text `_`), optional hotword and phrase-bias weights, and a stream operation of `OP_DECODE` (1, append frames and return a provisional n-best), `OP_FINISH` (2, append frames, return the finalized n-best, then clear that stream), or `OP_RESET` (3, clear only the named stream and return an empty successful n-best). A successful reply is JSON `{"ok": true, "requestId": <uint>, "hypotheses": [...]}`. Each hypothesis object has fields `ids`, `text`, `acoustic`, `bias`, `total`, `confidence`, and `spans` (half-open `[start, end)` frame indexes, one span per collapsed token; empty transcript ⇒ `spans: []`). A rejection is JSON `{"ok": false, "code": "<CODE>"}` with stable codes including `CTC_MALFORMED` and `CTC_NONFINITE`. Rejections leave later utterances' decode state unaffected.

Recognition quality is CTC path mathematics, not surface fluency. Blank versus nonblank transitions, repeated labels across blanks, log-sum-exp prefix merging, acoustic beam pruning, word-boundary completion scoring, finish-time finalization, and tied-hypothesis ordering (higher `total`, then higher `acoustic`, then lexicographically smaller `ids`) all belong to one inference model. Confidence is normalized n-best mass over the reported hypothesis totals and must sum to 1 when any hypothesis exists. Any legal chunk partition of an utterance must finish to the same collapsed tokens, ordered scores, alignments, and confidence as one-shot batch decode, and adding one finite constant to every logit in a frame must leave those same inference fields unchanged. Refresh the decoder binary with `/app/rehearse_caption_beam.sh`.
