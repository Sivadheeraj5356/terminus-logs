# Alignment and confidence note

A successful reply is JSON with shape `{"ok": true, "requestId": <uint>, "hypotheses": [ ... ]}`. Each hypothesis object uses this field schema: `ids` (integer array of collapsed token ids), `text` (UTF-8 transcript), `acoustic` (number, acoustic log score), `bias` (number, completed phrase-bias log score), `total` (number, acoustic + bias), `confidence` (number in [0,1]), `spans` (array of `[start, end)` integer pairs, inclusive start and exclusive end, one span per collapsed token). A rejection reply is `{"ok": false, "code": "<STABLE_CODE>"}` (for example `CTC_MALFORMED`, `CTC_NONFINITE`). Hypotheses are sorted by canonical total-score order. Repeated output tokens separated by blanks have distinct spans. An empty transcript has no token spans. Alignment for a selected sequence chooses deterministic high-probability frames consistent with the collapsed token order. Confidence is normalized n-best mass using total log scores (softmax over the reported `total` values, not `acoustic` alone), so the reported n-best confidences sum to one when at least one hypothesis exists. Extreme finite logits must produce finite scores, spans, and confidence. Vocabulary permutation with consistently permuted logits and token ids preserves transcript text and score ordering.
