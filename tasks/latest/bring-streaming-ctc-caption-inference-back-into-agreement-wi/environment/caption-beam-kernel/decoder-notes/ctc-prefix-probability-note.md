# CTC prefix probability note

Every frame is interpreted with stable log-softmax, subtracting the frame maximum before exponentiation. Adding the same finite constant to every logit in a frame leaves all log probabilities and hypotheses unchanged. The blank token is the declared blank index and is never emitted as a collapsed transcript token. Prefix beam search keeps separate blank-ending and nonblank-ending log probabilities for each collapsed prefix. A nonblank label equal to the final prefix label may extend only from the prefix blank probability; the same label after an intervening blank may produce a repeated output token. Distinct CTC paths that collapse to the same prefix are combined with log-sum-exp before pruning. Pruning is applied after prefix merging using acoustic plus completed-bias total score. N-best entries are unique collapsed token sequences. Ties are ordered by higher total score, then higher acoustic score, then lexicographically smaller token id sequence. Larger beam width may not remove the former best hypothesis for the same evidence. Non-finite logits are rejected with `CTC_NONFINITE`. Impossible dimensions, invalid blank index, unsupported beam settings, or malformed mailbox ranges are rejected with `CTC_MALFORMED`.
