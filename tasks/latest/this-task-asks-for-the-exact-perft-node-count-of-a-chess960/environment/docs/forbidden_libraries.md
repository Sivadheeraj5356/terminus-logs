# Forbidden dependencies

The move generator and search must be original work built from scratch
against the rules in rules.md. Do not link, include, vendor, or shell out
to Stockfish, python-chess, Leela Chess Zero, Fairy-Stockfish, any other
chess engine, or any chess rules or move generation library, including
bindings to one from another language. Do not bundle a Syzygy or Gaviota
tablebase file, an opening book, or any precomputed table of perft
answers. The build must not require network access.
