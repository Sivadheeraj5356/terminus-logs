# Memorandum M-2023-19 — Bound parameters mandate for telemetry statements

Date: 2023-11-02
From: S. Okonkwo
Disposition: adopted

## Purpose

Answers the board's request of 2023-05-09 (minute DRB-2023-11, item 3) for a
policy on SQL construction in station services.

## Background

Review of the spectral service found data-access methods that assemble SQL
by concatenating request-supplied text — channel identifiers and window
bounds — directly into statement strings. Because the station's channel
convention (memorandum M-2019-22) preserves punctuation verbatim, at least
one enrolled identifier contains a single quote, and concatenated statements
are malformed for that channel even absent hostile input.

## Mandate

Effective 2024-01-01, every SQL statement executed by station services
against the `telemetry` schema must pass request-derived values exclusively
through bound parameters supplied to the driver. Assembling any part of a
statement's values by string concatenation is prohibited from the effective
date. Statements whose text is entirely constant are outside the scope of
this mandate. Existing code was to be brought into compliance during the
2024 maintenance window; compliance work remained outstanding at the time
incident INC-2024-02 was recorded.
