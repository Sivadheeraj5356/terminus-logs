# Memorandum M-2024-31 — DRAFT — Internally hardened JDBC driver build

Date: 2024-08-27
From: F. Delacroix-Hume
Disposition: draft — never adopted

## Purpose

Proposes, in the wake of advisory MRA-2024-011, that the station maintain
its own hardened rebuild of the PostgreSQL JDBC driver, to be versioned
`42.7.4-hardened`, with the upstream parameter-encoding paths patched to the
station's own review.

## Proposal

The station would vendor the upstream 42.7.4 source, apply the parameter
handling patch set attached to this draft, and publish the result to the
station Maven repository under the `-hardened` version suffix. Services
would then link `org.postgresql:postgresql:42.7.4-hardened` in place of the
stock artifact.

## Status

This memorandum circulated in draft and was discussed informally in
September 2024. It was never brought to the board and was never adopted; no
`-hardened` artifact was ever built or published to the station repository.
Per SOP-9 §3, a disposition stated in a draft has no effect. The stock
42.7.4 artifact stands as the approved driver. The draft is retained in the
archive because later journal entries refer to it.
