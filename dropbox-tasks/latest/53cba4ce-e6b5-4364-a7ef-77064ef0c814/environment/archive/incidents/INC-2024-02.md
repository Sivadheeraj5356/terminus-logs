# Incident INC-2024-02 — Band-power request failures for O'Neill Ridge NW

Opened: 2024-02-08
Closed: 2024-02-12 (workaround), remediation deferred

## Event

Routine morning reporting failed for one channel. Every band-power request
naming the O'Neill Ridge NW fluxgate returned a server error, while the
same requests succeeded for the other five channels. The failing channel is
carried as `o'neill_nw` under the identifier convention of memorandum
M-2019-22.

## Finding

The service assembles its telemetry statements by concatenating the channel
identifier into the SQL text between single quotes. The apostrophe in
`o'neill_nw` terminates the SQL literal early, and the remainder of the
identifier is parsed as SQL, producing a syntax error on every request for
that channel. The failure mode is exactly the one the bound-parameters
mandate of memorandum M-2023-19 (effective 2024-01-01) was written to
prevent; the service had not yet been brought into compliance.

## Disposition

Reporting for the affected channel was produced manually for four days.
The compliance work was again deferred to the next maintenance window and
remained outstanding at the Station Systems Freeze. This incident is the
first recorded failure attributable to the interpolation defect.
