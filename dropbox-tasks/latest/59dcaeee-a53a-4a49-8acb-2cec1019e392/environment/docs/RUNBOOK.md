Build with `go build /app/environment/cmd/fieldloop`.

Run the bundled six-spin minor-loop study with:

`go run /app/environment/cmd/fieldloop --model /app/environment/fixtures/model.json --field /app/environment/fixtures/field.tsv --output-dir /app/output`

The study crosses several instability thresholds inside individual field intervals and includes reversals and equal-field holds.
