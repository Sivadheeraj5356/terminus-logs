# Data attribution

The derived relational fixtures in this task use UCI Clickstream Data for Online Shopping, UCI Machine Learning Repository, DOI 10.24432/C5QK7X, licensed CC BY 4.0. Source: https://archive.ics.uci.edu/dataset/553/clickstream+data+for+online+shopping. The task redistributes only deterministic derived tables; the original archive is not bundled. It preserves source session order and next-category observations while constructing and disclosing actions, terminal labels, target policies, and ambiguity semantics.
