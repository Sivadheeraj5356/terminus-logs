# Legacy Record Decoder — Output Contract

## Bundle Schema

The decoder outputs a JSON bundle at `/app/output/legacy_record_bundle.json` with the following structure:

```json
{
  "records": [
    {
      "seq_id": <int>,
      "datum_len": <int>,
      "checksum": <int>,
      "status_nibble": <int>,
      "revision_tag": <int>,
      "label": <string or null>
    }
  ],
  "compatibility_trace": [
    {
      "seq_id": <int>,
      "state": "compatible" | "diverged" | "malformed",
      "diverged_fields": [<string>, ...]
    }
  ],
  "error_classification": [
    {
      "seq_id": <int>,
      "kind": "truncated_header" | "invalid_checksum" | "overflow_field" | "reserved_bit_set" | "unknown",
      "detail": <string>
    }
  ],
  "artifacts": [
    {
      "group": "set_a" | "set_b",
      "record_count": <int>,
      "compatible_count": <int>,
      "diverged_count": <int>,
      "malformed_count": <int>
    }
  ]
}
```

## Round-Trip Guarantee

For each record in the compatibility_trace with state="compatible":
- The corresponding entry in the records section must have all fields matching the text export
- The record must not appear in error_classification

For each record in error_classification:
- The corresponding compatibility_trace entry must have state="malformed"
- The record must not claim compatibility

## Generation

The bundle is generated by the build pipeline:

```bash
/app/environment/scripts/build_all.sh
/app/environment/tools/bin/xscope --all-samples --bundle-out /app/output/legacy_record_bundle.json
```
