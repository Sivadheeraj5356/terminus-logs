# REST API reference

Base URL: `http://127.0.0.1:8000/api/v1`.

`GET /inference-batches/{batch_id}/` is cursor-paginated. The optional `cursor` query value is the last integer id from the preceding page; omit it for the first page. The server uses `inference_page_size` from `/app/config/repro_config.json`. Every response has exactly `batch_id`, `cursor`, `records`, `next_cursor`, and `page_sha256`. `cursor` echoes the requested integer or is null, `next_cursor` is the next integer cursor or null, and records may be unordered. Every record has exactly integer `id` and a `features` object containing exactly finite numeric `feature_0` through `feature_3`.

`page_sha256` is lowercase `sha256:` over canonical JSON bytes, without a trailing newline, of the other four response fields. A client follows cursors until `next_cursor` is null, rejects repeated cursors and duplicate ids across pages, and requires at least one record. `source_page_count` is the number of fetched pages. `batch_source_digest` is SHA-256 over UTF-8 lines `<page_sha256>\n` in fetch order, including the final newline.

`POST /drift-evaluations/` accepts exactly `batch_id`, `model_version`, `champion`, `training_oof_f1`, `training_calibrated_brier`, `decision_threshold`, `source_page_count`, `batch_source_digest`, `prediction_count`, `positive_predictions`, `mean_raw_positive_probability`, `mean_positive_probability`, `prediction_digest`, `prediction_psi`, `prediction_drifted`, `mean_tree_disagreement`, `disagreement_psi`, `disagreement_drifted`, `correlation_deltas`, `correlation_drift_score`, `correlation_drifted`, `leaf_js_divergences`, `leaf_drift_score`, `leaf_drifted`, `path_sketch_digest`, `path_sketch_js`, `path_sketch_drifted`, `drift_detected`, `drifted_features`, and `feature_stats`.

`drifted_features` follows feature order. `feature_stats` contains all four features, each with exactly numeric `mean`, `std`, `ks_statistic`, `psi`, and boolean `drifted`. `correlation_deltas` is an object whose six keys follow the correlation-profile pair order and whose finite values are in `[0,2]`. `leaf_js_divergences` contains exactly one finite value in `[0, ln(2)]` per champion tree and follows estimator order.

Digests use lowercase `sha256:` plus 64 hexadecimal characters. Counts are positive, positive predictions are within the prediction count, probabilities/F1/Brier/threshold and KS are in `[0,1]`, standard deviations and PSI are non-negative, and Jensen-Shannon values are in `[0, ln(2)]`. `correlation_drift_score` is the maximum correlation delta. `leaf_drift_score` is the configured linear quantile of the per-tree divergences.

Score all records in ascending integer `id` order. `prediction_digest` hashes UTF-8 lines `<id>:<calibrated probability formatted .12f>:<prediction>\n`, including the final newline. Feature KS is `scipy.stats.ks_2samp(training_column, batch_column).statistic`; feature PSI uses the stored feature profile and calibrated prediction PSI uses `prediction_profile`.

Tree disagreement is computed before calibration. For each row, collect every tree's positive-class probability, subtract their row mean, take the mean squared deviation, and take its square root. `mean_tree_disagreement` is the arithmetic mean over rows. `disagreement_psi` compares these row values with `disagreement_profile` using the same PSI definition as other profiles.

For dependence drift, recompute the documented Spearman coefficients on the batch, take the absolute difference from each stored coefficient, and emit those deltas in profile pair order. For per-tree leaf drift, use the union of stored and observed leaf ids for each tree. Place missing proportions at zero, add `leaf_js_epsilon` to every union element of both distributions, independently renormalize, and compute natural-log Jensen-Shannon divergence: half `KL(p || m)` plus half `KL(q || m)`, where `m=(p+q)/2`. `leaf_drift_score` is `numpy.quantile(leaf_js_divergences, leaf_drift_quantile, method="linear")`.

The path sketch captures the complete ordered leaf vector rather than individual-tree marginals. For every scored row, form `<path_sketch_salt>|<leaf_0>,<leaf_1>,...`, hash those UTF-8 bytes with SHA-256, interpret the first eight digest bytes as an unsigned big-endian integer, and reduce modulo `path_sketch_buckets`. `path_sketch_js` is natural-log Jensen-Shannon divergence between observed bucket proportions and `path_sketch_profile.bucket_proportions`, after adding `path_sketch_epsilon` to every bucket and independently renormalizing. `path_sketch_digest` hashes UTF-8 lines `<id>:<bucket>\n` in ascending id order, including the final newline.

Feature, prediction, disagreement, correlation, leaf, and path-sketch flags use strict `>` comparisons against their policy thresholds. Overall drift is true when at least `drift_feature_quorum` features drift or any non-feature channel is true. The API revalidates all aggregate scores, strict-boundary flags, ordering contracts, and the overall decision before persistence. `GET /drift-evaluations/` lists persisted evaluations newest first; `GET /health/` returns readiness state.
