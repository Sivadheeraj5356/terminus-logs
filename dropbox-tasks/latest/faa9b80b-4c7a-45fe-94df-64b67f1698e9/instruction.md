Planetary thermophysics for a synthetic Diviner-style lunar regolith column: recover subsurface temperatures, surface energy balance, multi-band brightness temperatures, and bounded thermal-inertia parameter fits from the frozen offline inputs under `/app/data` (materials, nonuniform depth grid, diurnal/eclipse/gradient illumination, forcing intervals, eclipse transmission, radiometer bands, observation queries, and inversion queries). Normative physics, units, tolerances, and the JSON shape live in `/app/docs` — especially `thermal_model_contract.md`, `radiometer_contract.md`, `inversion_contract.md`, `data_contract.md`, `report_contract.md`, `report_schema.json`, and `failure_contract.md`.

A successful run must write `/app/output/report.json` covering every accepted time step and observation: layer temperatures, surface fluxes, band radiances and brightness temperatures, one- and two-parameter inverse fits (conductivity scale / albedo offset) against the brightness-temperature targets, plus the diagnostics those docs require. Floats must be finite; stay fully offline from the shipped snapshot. The data directory and report path may be overridden (`lunar-regolith-solver --data-dir PATH --output PATH`; defaults `/app/data` and `/app/output/report.json`).

On any fatal input or numerical failure: nonzero exit, nonempty stderr, and remove any partial, temporary, or stale output.
