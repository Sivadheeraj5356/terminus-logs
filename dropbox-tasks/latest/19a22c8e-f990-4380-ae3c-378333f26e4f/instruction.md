A TypeScript program in `/app` fits an isotonic regression to a set of scattered points and predicts the fitted response at a list of query positions. It must reproduce `sklearn.isotonic.IsotonicRegression` exactly. It reads one JSON object from standard input of the form `{"inputs": [ ... ]}` and writes one JSON object to standard output of the form `{"results": [ ... ]}`, one `{"pred": [ ... ]}` per input in the same order, each holding one predicted value per query.

Each input gives the training predictors `x`, the matching responses `y`, an optional per-sample `weight` array (or `null` for unit weights), a boolean `increasing`, and the list of `queries` at which to predict. The `x` values are not guaranteed to be sorted and may contain repeats. The `increasing` flag selects the direction of the fitted monotone trend: when it is `true` the fit is constrained to be non-decreasing, and when it is `false` it is constrained to be non-increasing. The `weight` array, when present, gives each training sample its influence on the fit exactly as `sample_weight` does for the reference estimator. The `out_of_bounds` behaviour of the reference is fixed to `"clip"` for this task, so queries are treated the way that estimator treats them under that setting.

Fit the estimator to `(x, y)` with the given sample weights and direction, then predict at each query, matching `sklearn.isotonic.IsotonicRegression(increasing=increasing, out_of_bounds="clip")` value for value. Emitting plain JSON numbers is fine; the predictions are compared to the reference within a small floating-point tolerance (absolute and relative `1e-6`).

The standard-input reading, JSON framing, and output are already wired up in `/app/src/main.ts`, which calls `fitPredict`; the work is to complete that function in `/app/src/isotonic.ts`. Build the program with `make dist/isoreg.built`, which type-strips the entry through Node so the `isoreg` launcher runs it as `isoreg`.
