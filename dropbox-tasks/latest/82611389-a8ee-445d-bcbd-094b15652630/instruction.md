Stand up a CI build-train planner for a Fleet monorepo: resolve module DAG order, gate semver floors and registry approval, and publish compliance artifacts for release engineering.

Your deliverable is the fleetd HTTP planner plus the emit-fleet-build-audit.sh build-train driver. fleetd reads CSV module manifests, computes a stable topological build sequence, enforces policy from /app/config/fleet-policy.toml on every request, and exposes plans at POST /v1/build-plan plus plan seals at POST /v1/build-attest. The driver script reads /app/fixtures/fleet-release.pin, probes the live API including build-attest, rewrites policy to secure defaults, writes a compact probe snapshot to FLEET_STAGE_ROOT (default /app/var/fleet-stage) as /app/var/fleet-stage/build-train-probe.json, appends run-journal.jsonl, then exports /app/output/fleet-build-compliance.json.

Contracts are split across /app/docs/fleet-http-contract.md, /app/docs/build-graph-spec.md, /app/docs/module-fixture-index.md, /app/docs/fleet-policy-schema.md, /app/docs/fleet-build-compliance-schema.md, /app/docs/build-train-ops.md, and /app/docs/probe-snapshot-contract.md. Helpers under /app/lab are decoys and not on the export hot path.

fleetd binds LISTEN_ADDR (default 0.0.0.0:8080) and returns FLEETD_INSTANCE_ID on GET /health. Module approval state lives in the JSON registry at REGISTRY_DB_PATH. MANIFEST_PATH selects graph fixtures cataloged in /app/docs/module-fixture-index.md. Offline builds only (GOPROXY=off). Tear down any local fleetd listener after smoke checks.

After Go edits, rebuild with CGO_ENABLED=0 GOPROXY=off go build -o /app/bin/fleetd ./cmd/fleetd. Ensure PATH includes /usr/local/go/bin when go is missing from the shell. Do not edit /app/docs/, /app/fixtures/fleet-release.pin, /app/packages/catalog/loader.go, or /app/internal/registry/sqlite.go. Do not redeclare writeJSON or writeError in handlers; they remain in /app/internal/api/respond.go.

emit-fleet-build-audit.sh must honor API_BASE (default http://127.0.0.1:8080) and exit non-zero when probes fail or the API is unreachable. Policy TOML must use unquoted values per /app/docs/fleet-policy-schema.md. The probe snapshot must land on disk before the compliance JSON and stay byte-identical across idempotent reruns with unchanged inputs. Honor FLEET_STAGE_ROOT when set. Topological ordering follows the stable Kahn rule in /app/docs/build-graph-spec.md.
