A vendor DHCP lease daemon is installed on this host but not yet configured to operate. Do not change the daemon. Bring the lease service into full production through host administration. Its state lives in the SQLite database named by DHCPD_DB, default /var/lib/dhcpd/dhcp.db.

A correct host runs the service under a dedicated unprivileged dhcpd account and group, never root. It writes the config file /etc/dhcpd/dhcpd.conf that every command reads for the database and its pool, log, and backup directories. Those directories under /var/lib/dhcpd and /var/log/dhcpd are private to the account, and the lease database, built from the shipped schema, is owned by it and closed to others. It installs the control and maintenance commands on the system path and provisions the three required address pools under /etc/dhcpd/pools.d and no others, leaving the database clean.

Provisioning is idempotent and refuses overlapping pools, backups and restores carry integrity checks, state changing commands append to an audit log, and the maintenance jobs run through cron as the account, alongside resource limits and log rotation as the account. It also installs an advanced tier: a pool renumber command that re-homes a pool's leases, reservations, and declines to a new range in one transaction and refuses to overlap another pool, a consistency audit that reconciles the live tables against the pool ranges, and an attestation command that prints a canonical HMAC signed manifest of the database state. A dedicated operator group is delegated, through sudo, the right to run only the read only maintenance commands as the account and nothing else.

Every command reads its paths from DHCPD_DB and the other overrides, then the config file, then defaults, and acts as the user that invokes it. It must not drop privileges based on the caller, so when an override names a caller owned path it uses that path as the caller rather than dropping to dhcpd.

The full contract is in /app/SPEC.md, the commands in /app/COMMANDS.md, and the provided daemon in /app/README.md.
