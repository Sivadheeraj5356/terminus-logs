The formal language in /app represents one arithmetic expression over IEEE 754 double precision values. Its expressions contain number literals, the spellings inf and nan, free variables, unary minus, parentheses, and the binary operators plus, minus, times, and divide. The required artifact is a deterministic expression reducer that reads one program and emits the equivalent reduced program.

The accepted syntax is defined by /app/docs/grammar.md, while /app/docs/semantics.md defines evaluation, permitted reductions, and canonical numeric rendering. These documents form the behavioral contract. Constant subexpressions are evaluated using double precision semantics. An operand may disappear only when doing so preserves the exact result for every possible double precision value of every free variable, including signed zero, infinities, and nan. Transformations must preserve the parsed expression structure whenever the contract does not authorize a reduction. Reassociation is not permitted. A surviving binary application is printed fully parenthesized, and the complete result is printed as exactly one canonical expression followed by a newline. The output must parse again under the same grammar and retain the specified meaning.

The input is read from the file named by the optional first command-line argument, or from standard input when no file is supplied. The resulting executable is /app/foldc. The complete artifact is built from the C++ sources beneath /app/src by running /app/build.sh.
