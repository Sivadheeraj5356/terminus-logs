This is a Rust scientific simulation workspace under `/app/environment`. The suite models fog-of-war visibility replay over a rectangular cell grid, cadence-gated fade of stale coverage, ally observer pooling with resident-memory accounting, and a certified session ledger. The shipped build compiles and emits `/app/output/session_ledger.json`, but the ledger does not yet satisfy the full protocol contract. Plausible legacy code paths may still alias planes, use inclusive phase boundaries, or mis-scope checksums; the public contract is authoritative.

Read the public contract in `/app/environment/docs/field_rules.md` and `/app/environment/docs/api.md` (dual-plane replay, half-open phase windows, cadence_trace vs cadence_trace_v3 checksum scope, trace retention, pool provenance, tick parsing/rejection, ledger_digest composition, and recovery epoch semantics are defined there). Mode caps and decay cadence live under `/app/environment/specs_r/`. Scenario fixtures are discovered at runtime from `/app/environment/cases/g2/`. Preview banner tokens appear in `/app/environment/docs/lex_k.tsv`.

The recovery epoch contract includes both the emitter's state reader and the grader recovery hook at `/app/environment/docs/recover_k.txt`. That hook must implement the documented epoch-increment semantics against `/app/environment/state/recovery_epoch`. The grader runs each non-comment line of the hook as a separate `bash -lc` command, so every line must be self-contained with no cross-line shell variables. Do not execute purge or recovery yourself during normal certification — the grader invokes the hook — but the workspace must ship a correct hook.

Build with `bash /app/environment/scripts/forge_all.sh`, then certify with `/app/bin/k7 --suite g2 --ticks 12:0 --emit /app/output/session_ledger.json` (`12:0` expands to 120 ticks under `r0` `tick_scale`). The ledger must be `schema_version` 3 for suite `g2`, covering every discovered scenario under the public contracts, with correct dual-plane replay, grid geometry, phase windows, mode-aware cadence, ally pool footprint, tick parsing, provenance digests, and recovery epoch semantics. Do not hand-write the ledger, rely on the probe banner alone, or edit verifier artifacts.
