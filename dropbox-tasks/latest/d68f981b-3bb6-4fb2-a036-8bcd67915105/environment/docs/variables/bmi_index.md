# bmi_index

Pre-enrollment baseline index of standardized body-mass index, recorded for every employee at the start
of the year before any enrollment decision, so it is a pre-enrollment
characteristic and not a consequence of enrolling. Reported on a standardized
index scale. Baseline indices like this one may bear on both who enrolled and how
an employee's wellbeing evolves over the year; see `study_design.md` for how the
baseline measures shaped enrollment, individually and in combination.
