Repair the Haskell tool in `/opt/cnfprep` so `make -C /opt/cnfprep` builds `/opt/cnfprep/bin/cnfprep` and the executable preprocesses DIMACS CNF files correctly. In normal mode it runs as `/opt/cnfprep/bin/cnfprep INPUT --out OUT --log LOG --map MAP`. It must write a DIMACS CNF that is equisatisfiable with the input, has no duplicate literals, tautological clauses, unit clauses, pure literals, subsumed clauses, or applicable bounded variable eliminations left, and has a header that matches the emitted clauses.

The audit log is line based. It may contain `input`, `assign`, `drop`, `derive`, and `emit` records, but every output clause must appear as exactly one `emit ... 0` record and no `emit` record may describe a clause absent from `OUT`. The map file is also line based: it must contain `n N`, zero or more `f LIT`, `r VAR`, and `e VAR DEFAULT CLAUSE | CLAUSE ...` records sufficient for model extension. Extension mode is invoked as `/opt/cnfprep/bin/cnfprep --extend INPUT --map MAP --model PARTIAL --model-out FULL`; for any satisfying assignment of `OUT` written as `var=0` or `var=1` lines over the remaining variables, it must produce a complete assignment for variables `1..N` that satisfies `INPUT` and preserves those remaining-variable values.

The implementation should stay offline and deterministic. Do not change the command-line interface or require any files outside `/opt/cnfprep` and the paths passed on the command line.
