# Authority surface orientation

Four offline authorities interact during a profile run:

1. **Encode surface** — metadata binding before handoff.
2. **Decode surface** — object store tier depth after a simulated promotion shift.
3. **Walk surface** — metadata retrieval transport for delegated target generations.
4. **Export surface** — session row merge and report digest.

Active-step overrides may change target generation, expiry window, admission snapshot, and transport modes without changing profile defaults. Cross-store replica behavior, promotion epoch rules, and mirror-view recovery are in `stage_contract.md`. Export is valid only when gate, probe, and walk snapshots share the same step index.
