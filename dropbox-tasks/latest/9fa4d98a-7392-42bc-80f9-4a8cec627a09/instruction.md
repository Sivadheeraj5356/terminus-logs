A short secret message has been encrypted with a stream cipher whose keystream comes from a linear congruential generator, and your job is to recover the message. Each challenge file describes one generator in a few key equals value lines. It gives the modulus width in bits, a run of consecutive full width outputs the generator produced from its seed, the number of high order bytes taken from each later output to form keystream, and the ciphertext in hexadecimal. The modulus, the multiplier, and the increment are all secret, and the multiplier is never one. The keystream is drawn from the outputs that come after the published run, so the published outputs are not themselves the keystream. The full contract, covering the recurrence, the input fields, the keystream rule, the encryption, and the plaintext shape, is in /app/environment/docs/CHALLENGE.md, and everything graded is stated there, so read it first.

Grading uses a family of fresh challenges, not the one in front of you, so a recovery that only guesses the visible message will not pass. A Rust program lives at /app/environment, with the input parsing and output path already in place and the recovery left for you in /app/environment/src/main.rs. Build it with the provided Makefile. It takes one challenge file path as its argument and prints the recovered plaintext on one line, exiting zero, while malformed input prints the single line ERROR and exits one. Output is compared byte for byte, so print nothing else.
