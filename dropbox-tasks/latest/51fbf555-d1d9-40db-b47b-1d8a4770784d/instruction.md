A dual-PLC factory segment runs Time-Sensitive Networking with scheduled gate control across three switches, a redundant cross-link, and asymmetric bottlenecks under maintenance derating. Topology, gate schedules, traffic classes, periodic message flows, clock synchronization offsets, packet traces, and the TSN profile overview live under `/app/data/`. Behavioral rules — WCET composition, compliance deadlines derived from traffic-class shaving in `traffic_classes.json`, queue guard bands on gate schedules, bandwidth reservation with per-flow overhead bytes, switch-only clock-skew accumulation with trace jitter, trace miss deduplication when clock skew supersedes observed misses, scheduling-exempt flows, gate-window conflicts, priority-inversion detection, trace validation filtering, metric formulas, and output schemas — are defined in `/app/data/validation_policy.json`. When the overview in `tsn_profile.json` disagrees with the policy or bundled inputs, follow the policy.

Build `/app/solution/solve.sh` to read those inputs and write four deterministic artifacts under `/app/output/`: `schedule_validation_report.md`, `deadline_misses.json`, `gate_conflicts.json`, and `network_utilization.csv`. Identical inputs must yield identical outputs on every run. Each output artifact's `sort` field in `validation_policy.json` defines final array ordering (for deadline misses, rank `miss_type` by `miss_type_output_order`, not alphabetically). Assign `conflict_id` values only after sorting gate conflicts per policy; coerce trace timestamps to float before latency rounding; follow `report_markdown.blank_line_after_section_heading` for the markdown report. Miss detection and `margin_us` use compliance deadlines from traffic classes, but each miss entry's `deadline_us` field and `{deadline_us}` text in `description_templates` must render the nominal integer `flow.deadline_us` (see `description_templates.placeholder_rules`). Flows marked `enabled: false` or `scheduling_exempt: true` and traces marked `validate: false` must be excluded from the analyses described in the policy for their respective scopes.
