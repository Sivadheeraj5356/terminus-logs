Your bench monitor uses `/app/repo/bin/trace_blur` to smooth one-dimensional sensor traces before thresholding. The program reads one JSON file argument with top-level shape `{"inputs":[...]}`. Each input record has `signal` and `sigma`, with optional `mode` and `truncate`. It must print `{"results":[...]}`, keep the input order, and put one `filtered` array in each result with one value per input sample.

For each record, match `scipy.ndimage.gaussian_filter1d` on a one-dimensional float signal. `sigma` is required. Valid `mode` values are `reflect`, `nearest`, `wrap`, and `constant`; missing `mode` means `reflect`. In `constant` mode, out-of-range samples have value `0`. Missing `truncate` means `4.0`. `truncate` is the positive multiplier used to cap the Gaussian kernel at `round(truncate * sigma)` samples on each side of the center. Boundary handling, kernel weights, radius rounding, and numeric output should follow `scipy.ndimage.gaussian_filter1d` exactly.

Reject a malformed JSON request with a non-zero exit status. Also reject any record with an empty signal, a non-finite signal value, a non-finite or non-positive `sigma`, an unsupported `mode`, or a present `truncate` that is non-finite or not positive. The current implementation is only a short moving-average shortcut and does not reproduce the required filter.
