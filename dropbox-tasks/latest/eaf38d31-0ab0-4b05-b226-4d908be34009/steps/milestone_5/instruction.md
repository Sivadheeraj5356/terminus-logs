A certificate-transparency monitor receives a presented cross-signing trust graph and must classify each key. Implement this in a flat module at exactly /app/transparency/trustgraph.py (importable as from trustgraph import analyze_trust_graph with /app/transparency on sys.path). analyze_trust_graph(graph) takes one dict and returns {"nodes": {<key id>: <verdict>}, "summary": {...}}.

graph["nodes"] lists present keys, each a string id or a dict {"id": <key id>, ...} that may carry a truthy "compromised" field marking the key revoked (a key is compromised if any occurrence flags it; a bare string never is). graph["edges"] lists directed assertions, each a 2-element [src, dst] list/tuple or a dict {"src": <id>, "dst": <id>}; an edge a -> b means b vouches for a (direction matters). graph["roots"] lists trust-anchor key ids (may be empty or absent).

Normalize first: duplicate node ids collapse to one vertex carrying all its edges, never inflating SCC size or the node count. A key is present iff its id appears in nodes. An edge whose dst is absent is a dangling edge, removed before cycle analysis and only tallied; an edge whose src is absent is dropped and not tallied. Edges deduplicate by (src, dst), so identical repeats count once.

The nodes mapping has one entry per present key, and all keys in one strongly-connected component (SCC) share their scc_rep, scc_size and the four condensation fields. in_cycle is True iff the key reaches itself over present edges. scc_rep is the lexicographically smallest id in its SCC. scc_size is the count of distinct keys in its SCC. unreachable is True iff no present root reaches it over present edges (a root reaches itself). rank is None iff in_cycle, else the 0-based layer: the longest chain of non-cyclic predecessors ending at the key (0 if none), where a predecessor of k is any present p with an edge p -> k and cyclic predecessors do not count.

The four condensation fields collapse each SCC to one super-node keyed by scc_rep, keeping only distinct cross-component edges (intra-component and self edges ignored, parallels once); a super-node's predecessors are the super-nodes with an edge into it. trust_depth is 0 for a source, else 1 plus the maximum predecessor trust_depth, an integer for cyclic keys. weighted_trust_depth is the same chain but each component adds its scc_size: its own scc_size for a source, else its scc_size plus the maximum predecessor value. clean_trust_depth counts only clean components — a component is dirty iff any member is compromised; a dirty component's members are 0, and a clean component is 0 when it has no clean predecessors (a clean source is anchored at 0, exactly as trust_depth anchors a source at 0), else 1 plus the maximum clean_trust_depth over its clean predecessors only. root_distance is None iff unreachable, else the fewest forward hops from a root over the same condensation: 0 for a super-node holding a present root, else 1 plus the minimum predecessor root_distance.

graph["summary"] holds num_sccs (counting singletons), num_cycle_sccs (size at least 2, or a self-loop), largest_cycle (largest cyclic component size, else 0), is_acyclic, num_unreachable, dangling_edges, the maxima max_trust_depth, max_weighted_trust_depth, max_clean_trust_depth and max_root_distance (each 0 when no key qualifies), and num_compromised. Keep this exact importable name: analyze_trust_graph(graph).
