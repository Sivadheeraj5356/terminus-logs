# Counter-system safety analyzer

`/app` contains a Go analyzer for counter systems — the model behind resource pools, work queues, and token schemes. It reads one job as JSON on stdin: a number of counters, rewrite rules that atomically consume and produce counter units, a start state, and a list of cover queries, each asking whether the system can ever hold at least the queried amounts on all counters simultaneously. It writes one verdict per query as JSON on stdout — a `covered` array of booleans in query order. Verdicts must be exact for reachability at any depth, and the analyzer must decide every conforming job in bounded time — including systems whose counters can grow without limit, where the reachable state space is infinite. On several such systems the current analyzer returns verdicts that are simply not the truth values defined by the contract: run the jobs under `/app/samples/` against the matching `.expected.json` files to see a system where it claims a combination is attainable that the rules can never actually produce.

The complete contract — system semantics, the cover question, the exactness and termination obligations, and validation — is in `/app/docs/spec.md`, with the I/O schema in `/app/docs/output_schema.md` and terms in `/app/docs/glossary.md`. The specification defines what a correct verdict is, not how to decide it; finding a decision procedure that is simultaneously exact on unbounded systems and always terminating is the work. Make the analyzer produce exactly the specified verdicts for every conforming job and the malformed verdict `{"malformed": true}` otherwise — for systems well beyond the shipped samples.

Implement your changes only in `/app/analysis/analysis.go` — that is the sole editable file. Everything else, including `/app/main.go`, `/app/go.mod`, and everything under `/app/model/`, is read-only and will be restored to its original contents before grading; do not add, remove, or rename any file. The analysis may use only the Go standard library and the provided `coverd/model` package; do not use process execution, the file system, networking, environment access, reflection, `unsafe`, or cgo. Build from `/app` with `go build`.
