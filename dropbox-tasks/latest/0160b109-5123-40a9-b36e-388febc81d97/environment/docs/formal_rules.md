# Formal properties

## Artifacts

- `/app/output/conversion_ledger.json` regenerated by `/app/bin/ucg_run`
- `/app/output/run_traces/` one trace file per run, named `<arm>_<phase>.trace` (for example `arm0_cold.trace`, `arm0_warm.trace`, `arm1_warm.trace`). Each trace records `cache_loaded=`, `cache_dropped=`, the active arm salt, and `edges=` equal to how many `[[edges]]` rows were loaded from `edge_seed.toml`.
- `/app/output/cache/<tgt_id>.bin` 8-byte big-endian facet blobs (for example a1.bin, b2.bin, a1_echo.bin)
- `/app/output/cache/arm_tag` records which arm minted the current cache tree
- `/app/output/journal/tip.toml` records the last successful bind tip with lines `arm = "..."`, `phase = "cold"` or `phase = "warm"` or `phase = "replay"`, `digest = "..."` (primary ledger digest), and `bind = "..."` (id-bound cache digest over every primary and echo)
- `/app/environment/data/edge_seed.toml` directed conversion edges applied after per-target mix, in file order
- `/app/environment/data/arm_ladder.toml` arm salts, primary order, and the first `[[mutations]]` block used by replay
- `/app/environment/data/coeff_seed.tsv` per-target `step`, `family`, and `prev` inputs

Terminal cold and replay digests, and cold arm0 facet witness bytes, are held only by the verifier harness (fixtures named `arm_targets.toml` and witness files such as `arm0_a1.bin` under the harness `fixtures` tree). They are not shipped under `/app/environment/data/`.

The verifier grades by copying `/app/environment` into `/var/tmp/ucg_verifier_src`, running `go build` directly into `/var/tmp/ucg_verifier_bin` with GOCACHE `/var/tmp/ucg_go_cache` as unprivileged user `ucgbuild` (not via the submitted `build_ucg.sh`), then running that binary with PATH including `/opt/verifier/bin`. That user has no read or execute access to `/tests` or `/solution`. The harness may chown `/app/output` artifacts so `ucgbuild` can rewrite cache, journal, traces, and the ledger during grading. The harness also runs the same binary against verifier-owned alternate seeds under `/var/tmp/ucg_alt_root` (via `UCG_ROOT`) whose coeffs, edges, and arm ladder differ from the editable `/app/environment/data` tree. Alternate expected digests live beside the harness fixtures as `alt_targets.toml` with witness names such as `alt0_a1.bin` under fixture trees named `alt_seed` and `alt_witness`.

## Row shape

Row fields in `rows` are as follows.

- `tgt_id` field (string id for each conversion target)
- `facet_hex` field (exactly 16 lowercase hex characters)
- `lag` field (integer; mirror pairs require 0)
- `feat_rc`, `dep_rc`, `ord_rc` fields (integers; coherent terminal runs use 1)
- `sync_label` field (string; terminal coherent runs use `settled`)

The summary schema fields are as follows.

- `ledger_digest` is the sha256 hex over the comma-joined sorted primary `facet_hex` values for ids in `/app/environment/docs/tgt_ids.txt` (a1, b2, g3); echoes are excluded; see digest reduction home in `t4w/cmd/ucg_run/main.go`
- `rows_total` field counts emitted rows
- `span_band` field set to 16

## Facet algebra (uint64 wraparound)

All arithmetic below is uint64 wraparound. For each target row from `coeff_seed.tsv`, with active arm `salt` from `arm_ladder.toml`:

1. `base = (family << 32) | prev`
2. `mixed = base XOR (step * 0x9E3779B97F4A7C15)`
3. `provisional = mixed XOR salt`

Diagnostic helpers beside the live fold path must not alter `provisional` (the live fold is bare mix, not a stamped diagnostic transform).

After every target has a provisional facet, apply each edge from `/app/environment/data/edge_seed.toml` in file order:

4. `destination = destination XOR (source * weight)`

Then each `_echo` twin copies its primary facet (a1_echo copies a1, and likewise for b2 and g3).

Durable bind then mixes the primary's `step` stamp into the blob. For a primary and its echo, `step_stamp` equals that primary's `step`:

5. `durable = provisional XOR (step_stamp * 0x100000001)`

`facet_hex` and the 8-byte cache blob are that durable value. Identical warm rebinds must keep a healthy durable blob unchanged when the recomputed durable matches the loaded blob.

## Replay order

Pipeline order for a rebind is:

1. Load coeffs, arm order, arm salt, and edges.
2. If `--phase replay`, or if `--phase warm` while the journal tip for this arm still records `phase = "replay"`, apply the first `[[mutations]]` block from `arm_ladder.toml` (add `delta_step` to the touched primary's `step` only) before mix.
3. Expand each primary id to `primary` then `primary_echo`.
4. On warm or replay, consult `arm_tag` before loading `/app/output/cache/*.bin`. Foreign-arm bins are dropped (`cache_dropped` counts them). Same-arm bins may be trusted only when the tip arm matches, the primary `digest` matches the tip `digest`, and the tip `bind` matches an id-bound digest over every expanded target: sorted `tgt_id=facet_hex` pairs for all primaries and echoes, where each echo hex equals its primary. Swapping two primary bins or changing an echo must fail that bind check and force a re-fold.
5. Compute provisional facets (side effects before gate recording when `gate_first` is false), apply edges in file order, sync echoes, then durable-bind each expanded id.
6. Emit ledger rows, refresh cache bins, write `arm_tag` and journal tip, write the phase trace.

Replay step bumps replace the old `step * 0x9E3779B97F4A7C15` product inside `mixed`, so an upstream bump also moves edge-downstream primaries after step 4 of the algebra.

## Facet authority

Cold arm0 durable facets and digests must match the verifier-held witnesses and targets. Cold digests for every arm in `arm_ladder.toml`, and the arm0 replay digest, must match those verifier targets. Arms with nonzero salts must differ from arm0 on at least the touched primary facets.

Identical warm rebinds on a healthy same-arm tree keep the prior digest. A warm rebuild may reuse loaded bins only when `arm_tag` matches the active arm, tip `digest` matches the primary ledger digest of those bins, and tip `bind` matches the id-bound primary-plus-echo map described above. Otherwise the pipeline must re-fold, re-apply edges, and rebind.

## Phase behavior

- `--phase cold` builds durable packs from the TSV seed with side effects before gate recording. Traces must report `cache_loaded=0`. Writes `arm_tag` and journal tip for the active arm.
- `--phase warm` consults `arm_tag` and journal tip before trusting bins. Foreign-arm bins must be dropped (`cache_dropped` counts them) and the active arm must be recomputed. Healthy same-arm cache stays idempotent. Corrupted bins must repair to the derived facet for the active tip. If the tip phase is `replay` for the same arm, warm must keep the mutated seed in force while repairing or rebinding so the digest stays on the replay target rather than collapsing to cold.
- `--phase replay` reloads acceptable same-arm bins, applies the first `[[mutations]]` block from `arm_ladder.toml` (step bump on the touched primary only), then rebinds. Upstream bumps move edge-downstream primaries. The mutated arm0 `ledger_digest` must match the verifier-held replay target.
- `--status` after a coherent cold run prints `durable_match=true` and `sync_label=settled`. `--status-only` after cache corruption without a repair rebuild prints `durable_match=false` and `sync_label=drift`.

## Coherence

1. For each `tgt_id`, `facet_hex` matches the lowercase hex of the 8-byte cache blob.
2. Mirror pairs (`a1`/`a1_echo`, `b2`/`b2_echo`, `g3`/`g3_echo`) share identical `facet_hex` and lag of zero.
3. After `--phase warm` on a healthy same-arm tree, digest matches the preceding cold run on that arm.
4. After `--phase warm` following a same-arm replay tip, digest matches the replay target even if a cache blob was corrupted before warm.
5. Cross-arm warm without clearing cache must not leave the previous arm's digest in place; `arm_tag` and tip must track the active arm.
6. Static writes of `conversion_ledger.json` without the driver are invalid.
7. Status stdout reports sync_label settled only when durable_match is true.
