The code under /app/environment is framewire, a small in-house Go library that encodes PostgreSQL frontend protocol messages onto the wire. The encoders live under /app/environment/internal/proto, the buffer helpers under /app/environment/internal/wireio, and a command line driver sits at /app/environment/cmd/framewire. Each message is framed with a one byte type tag and a four byte big endian length prefix, and every well formed message encodes today. Several encoders and the send path can be driven with a crafted message into emitting an oversized or miscounted frame instead of refusing it, and a peer then re splits the stream and treats attacker controlled trailing bytes as a fresh message, which is how an oversized query or bind parameter smuggles a second SQL command past the driver.

Audit the encoders, the shared header helper, the buffer helpers, and the send path. Close every place where a length or count taken from a message is used to size, index, or advance a buffer without being validated against the limit that applies to it, and every place where the arithmetic meant to enforce that limit can itself pass when it should fail. Do not assume one weakness per file, that a file holds exactly one, or that an encoder that already performs a size check is safe. The number of fixes is yours to work out, and a limit that one message enforces may be the limit another message forgets.

Read /app/environment/docs/security-spec.md first, since it pins down the framing, the protocol maximum, and what a refusal must look like. A refusal is an ordinary returned error whose text leads with the subsystem it came from, the message kind for a per message check, framing for the shared header helper, or send for the transmit path, and names what was exceeded. A message exactly at the maximum is legal and must still encode, a refusal must never be a panic, and the send path must surface a refusal rather than transmit anyway. Sample specs live under /app/environment/testdata; they illustrate the family of hostile inputs rather than cataloguing every one, so refusing only the samples is not the same as satisfying the contract.

Go is on the PATH, so build with go build ./... from /app/environment, and there is no internet access so do not install anything. When the code is fixed, write a short security_notes.md at /app/environment/security_notes.md that names each subsystem you hardened using its exact lowercase label, which are query, bind, copydata, funcall, batch, and formats for the per message encoders, framing for the shared header helper, and send for the transmit path, gives the vulnerability class as CWE-190 leading to CWE-89, and records that the design is inspired by the pgx PostgreSQL driver and that the upstream is MIT licensed.
