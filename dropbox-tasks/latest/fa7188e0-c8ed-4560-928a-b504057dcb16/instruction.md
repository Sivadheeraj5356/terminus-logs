This is a hand-off of a half-finished groundwater model in `/app`. The site setup is in `/app/site_config.json`, and `/app/model_notes.md` defines the transport physics, numerical behavior, sampling rules, well interpolation, and output details. The current transport and sampling modules are stubbed, so the reported risk numbers are not usable.

Implement the reusable JavaScript logic in `/app/simulate.js`, `/app/step_transport.js`, and `/app/sample_aquifer_params.js`. `/app/run_risk_study.js` should remain the Node driver that imports and calls those modules for the baseline case and the seeded Monte Carlo study. The final simulation should match the transport behavior described in `/app/model_notes.md`: downgradient plume movement, flow-oriented spreading, sorption slowdown, attenuation, zero-gradient edge behavior, and continuous source release. Keep final grids finite, nonnegative apart from rounding noise, bounded by `source_conc` apart from rounding noise, and physically sensible. Do not hard-code expected output values or bypass the final simulation grid: every reported baseline and Monte Carlo well concentration must be bilinear interpolation from that run's final grid.
