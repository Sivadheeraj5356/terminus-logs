# Annex q46 boundary keys

When the south band profile (`p8`) is active, a filtered subset of annotation keys participates in unit_tag material. The overview intentionally omits which prefix and relative order apply.

Authoritative annex prefix, relative order versus labels, seal table, window modulus, stage root, and digest form live as KEY=VALUE lines in `/app/environment/fixtures/slices/q46.txt` plus `docs/stage_rules.md`, `docs/seal_windows.md`, and `docs/tip_chain.md`. Non-matching annotation keys never enter unit_tag material.

The south band profile sets annex_keys true in `/app/environment/profiles/p8.toml`. Per-band scope letters are profile fields, not the historical `N`/`S` letters from older probes.

Crossing from a band with annex off into a band with annex on for the same manifest advances the durable cache epoch. Changing seal window across mixes for the same manifest also advances the epoch. Journal segments accumulate across both bands until wipe.
